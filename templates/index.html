Keyboard navigation
  • Tab / Shift + Tab — move between controls.
  • Enter / Space — activate buttons and toggle checkboxes.
  • ← / → — move through toolbar or bot buttons. Home / End — first / last button.
  • ↑ / ↓ on a bot button — move to the previous / next bot.
  • Escape — close a dialog. Unsaved edits still require confirmation.
  • Focus a command output box with Tab, then scroll with arrow keys or Page Up / Page Down.
  • Hold Alt + Shift and press J for Jobs, N to add a bot, R to refresh, B for bot controls, or K for this help.
Shortcuts work on the dashboard outside text fields and dialogs.
